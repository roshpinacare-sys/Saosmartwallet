- **פתיחת-כספת**: `/api/gate/unlock-key` עם מפתח-ה-owner מהקבצים שהעלה הבעלים → אימות-חי מול HIVE → `hive/headcorner@owner` ✓ (חותם-פתיחה קיבל, GCM אישר)

- **אטימה**: **10 סודות חדשים נאטמו** (AES-256-GCM תחת מפתח-האב):
  - 1× NVIDIA NIM **חדש** (השני בקובץ התגלה ככפילות-דדופ תקינה) → **pool-המוח = 4 מפתחות** (nv-fp:1e33…, 596a…, 531b…, +infrastructure)
  - 2× GitHub PAT — אחד חי ומזוהה כ-`roshpinacare-sys` (החשבון-של-13-הריפו!), השני fine-grained (imported)
  - 4× מפתחות-EVM/hex (נגזרו כתובות) · 3× מנטרות (טביעת-אצבע `mn-fp:…`, הביטוי-עצמו אף-פעם לא ציבורי)
  - כל ה-WIF-ים של headcorner: כבר-היו-בכספת (דדופ לפי-pubkey ✓)
- **תיקון-מעלה (r28-distinct-slots)**: `keys-batch` — יעדי-ה-fallback הגנריים התנגשו על `(kind,role,pub=null)` וכך רק ארנק-hex-אחד ומנטרה-אחת יכלו-להתקיים. עכשיו: hex/evm → pubkey-נגזר; מנטרה → `mn-fp:` sha256. **249 רשומות בכספת** (178 verified / 24 imported / 45 rotated-out).
