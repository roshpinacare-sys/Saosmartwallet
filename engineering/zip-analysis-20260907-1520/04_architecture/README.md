| פריט | ערך |
|---|---|
| מסמכי ארכיטקטורה למערכות שנמצאו | **0** |

## קבצים שייווצרו כאן לאחר קבלת קלט

- `architecture-<system-name>.md` — ארכיטקטורה לוגית ופיזית לכל מערכת (רכיבים, זרימות נתונים, ממשקים, תלויות רשת, מודל איומים).
- `system-map.md` — מפה משווה בין כל המערכות שחולצו.
