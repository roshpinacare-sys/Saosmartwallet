## 2. מה בדיוק נדרש כדי להמשיך (checklist להעלאה)

- [ ] **קובצי ה-ZIP עצמם** — העלאה ישירות לשיחה (או פירוק לתיקייה והעלאת התיקייה).
- [ ] **או קישורי מאגרים ציבוריים** (GitHub/GitLab public) — יש לוודא שהמאגרים פתוחים לקריאה אנונימית.
- [ ] **רישיון הקוד** (MIT / GPL / AGPL / ללא רישיון) — קובע מה מותר לבנות ולהפיץ.
- [ ] **הבהרה מילולית מהו `steem main`**: fork של `steemd`? רשת פרטית חדשה? צומת מלא? שם repo?
- [ ] **רשימת סודות שנכללו ב-ZIP** (אם יש) — כדי שיסומנו ויוחרגו מניתוח תוכן.

## 3. כללי בטיחות להעלאה חוזרת

1. ✏️ **עודכן 2026-09-07:** הטוקן ב-`Roshcaregt.txt` המקורי נחסם ע"י המערכת ולא היה שמיש — אין לו סיכון. **הטוקן התקין הנוכחי בהיקף רחב** (repo/admin/org) — מומלץ לצמצם היקף ל-`repo` בלבד או לשלול אותו לאחר השימוש ב-push.
2. לא לכלול `.env`, מפתחות פרטיים, seeds, `wallet.dat`, או קבצי מפתח בתוך הארכיונים.
3. הסריקה הבאה תחסום אוטומטית קבצים רגישים-לכאורה מהצגת תוכן (כפי שנעשה כאן).
