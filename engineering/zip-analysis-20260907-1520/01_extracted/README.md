# 01_extracted — תוצרי חילוץ

## ייעוד התיקייה

כל ארכיון מ-`../00_input/` מחולץ לתיקייה משלו כאן, בשם שם הארכיון (ללא סיומת), למשל: `01_extracted/steem-main/`.

## סטטוס נוכחי

| פריט | ערך |
|---|---|
| תיקיות חילוץ | **0 (ריקה)** |
| סיבה | אין ארכיונים לחילוץ — לא בוצע חילוץ כלשהו |

## כללי חילוץ מחייבים

1. חילוץ נעשה **אחרי** סריקת סודות ולא לפני.
2. כל ארכיון לתיקייה נפרדת — אין ערבוב פרויקטים.
3. קבצים בינאריים גדולים (block logs, תמונות) מתועדים בשמם בלבד.
4. אסור להריץ סקריפטים/builds מהתוכן החלוץ בשלב הניתוח — קריאה בלבד.
5. אחרי חילוץ: יצירת `manifest.md` בתוך תיקיית החילוץ (עץ קבצים, ספירות לפי סוג, קבצים שהוחרגו).
