# 00_input — קלטים מקוריים

## ייעוד התיקייה

כאן נשמרים **עותקים בלבד** של קובצי הקלט המקוריים (ZIP ודומיהם) שהועלו על-ידי המשתמש. המקורות ב-`upload/` אינם נוגעים; עובדים על עותקים.

## סטטוס נוכחי

| פריט | ערך |
|---|---|
| קבצי קלט בתיקייה | **0 (ריקה)** |
| סיבה | לא נמצאו קובצי ZIP בסביבה — ראה [`../02_reports/environment-scan.md`](../02_reports/environment-scan.md) |

## נוהל קבלה (כשיתקבלו קבצים)

1. העתקה של כל קובץ לכאן (ללא שינוי שם).
2. חישוב SHA-256 לכל קובץ ותיעוד בטבלה למטה.
3. סריקת תוכן לאיתור סודות לפני כל חילוץ — קבצים חשודים מסומנים ומוחרגים.
4. חילוץ כל ארכיון לתיקייה נפרדת ב-`../01_extracted/<archive-name>/`.
