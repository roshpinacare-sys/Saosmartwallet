# 03_code_analysis — ניתוח קוד

## סטטוס נוכחי

| פריט | ערך |
|---|---|
| מסמכי ניתוח קוד | **0** |
| סיבה | **לא נמצא קוד לניתוח** — אפס קובצי ZIP ואפס תיקיות קוד של בלוקצ'יין בסביבה (אומת בסריקה: [`../02_reports/environment-scan.md`](../02_reports/environment-scan.md)) |
| עמדה הנדסית | לא ייכתב ניתוח קוד שלא בוצע. לא יומצאו ממצאי קוד, תלויות, או ציונים ללא קוד בפועל |

## כללים לכתיבת ניתוח עתידי

1. ניתוח מתבצע **רק** על תוכן שחולץ ל-`../01_extracted/`.
2. כל מערכת תקבל מסמך `analysis-<system-name>.md` לפי התבנית: [`analysis-template.md`](./analysis-template.md).
3. כל שדה בתבנית חייב להיות מבוסס על הקוד שנצפה בפועל (נתיב קובץ/שורה כאסמכתא) או לסומן "לא ניתן לקבוע".
4. ציון 1–10 הוא פונקציה משוקללת של השדות — יש לציין את המשקלים במפורש.
